# 📚 BookSnap

> [BookSnap 서비스 시연 영상](https://www.youtube.com/watch?v=dJb3Et3U0Gw) <br>
> **BookSnap**은 소설의 이야기를 가지고 카드 뉴스를 생성해주는 서비스입니다.<br>
> 소설의 내용을 간단하게 전달하면 내용 요약과 함께 그에 걸맞는 이미지를 생성해주는 웹 애플리케이션입니다.<br>

## ✨ 주요 기능

### 📱 핵심 기능

- **소설 내용 입력**: 원하는 소설의 내용을 입력
- **카드 생성**: 소설 내용 기반으로 카드 (요약된 글 + 이미지) AI 생성
- **카드 탐색**: 다양한 소설의 카드 뉴스를 조회 및 탐색
